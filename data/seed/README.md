# Seed data

- `jobs.json` — 311 synthetic postings from 40 fictional companies (apply URLs on example.com). Generated by `node scripts/generate-seed.mjs`; includes stale, scam-pattern and cross-agency duplicate examples to exercise the quality filter.
- `h1b_sample.csv` — a small sample shaped like the USCIS H-1B Employer Data Hub export (fictional seed companies plus a few well-known employers with illustrative counts). Load the real file with `npm run h1b:load -- <file.csv>`.
- `resumes/` — three sample résumés (TXT, PDF, DOCX) for onboarding demos and tests.
